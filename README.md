# ANG PH

Handcrafted Filipino furniture website.

## Website versions

- [Updated V2](website/ang%20ph%20website%20version%202%20updated.html) — current version with separated collection cards.
- [Updated V1](website/ang%20ph%20website%20version%201%20updated.html) — alternate layout.

Open either HTML file in a browser to preview. Images are served from Cloudinary; source assets are included in `website/assets/`.

Original versions and supporting design files are retained for reference. There is currently no `index.html` or configured deployment.
